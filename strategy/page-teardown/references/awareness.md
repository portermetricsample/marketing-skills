# Awareness levels

How much the reader already knows when they arrive. **The spine of a page:** the level (or levels) it serves decides where it starts and how much problem-education it needs before it can sell. (Eugene Schwartz's five stages.)

| Level | What they know | Where the page has to start |
|---|---|---|
| **Unaware** | Doesn't know they have the problem | Name the problem before anything else |
| **Problem aware** | Knows the problem, not that solutions exist | Show the cost of it, then that a fix exists |
| **Solution aware** | Knows solutions exist, not this one | Position this as the category, then differentiate |
| **Product aware** | Knows this one, not convinced | Proof, comparison, objections |
| **Most aware** | Convinced, needs the terms | Pricing, CTA, the fine print — fast |

**How it drives the page.** A conversion landing page usually targets **one** level and runs a single linear spine. A **homepage** serves **several at once**, top to bottom — the hero speaks to the more-aware, mid-page educates the less-aware, the close converts the most-aware. Which of the two you're reading is a property of the page itself, and it shapes which **sequence** fits and where it starts.

**In a teardown:** name the levels the page serves, the one it *starts* at, and the ones it *skips*. A page that opens on the outcome with no problem-education is betting on warm, solution-aware traffic — a deliberate, consequential choice worth flagging.
