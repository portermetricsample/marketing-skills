# Persuasion sequences

The order a page persuades in. A page follows one, blends several, or builds its own — in a teardown, name the dominant pattern (and the blend, if it shifts stage to stage). Each is a *stage → what it assembles* recipe. Bracketed names resolve to [`sections.md`](sections.md) (page components) and the message components read off the page.

| Sequence | The stages |
|---|---|
| **AIDA** | Attention (`[Hero]` with the outcome vs the pain) → Interest (break down the `[Problem]`, show the future) → Desire (`[Features]` + `[Benefits]` through `[Use cases]`, handle `[Objections]`) → Action (`[Pricing]` + `[CTA]`) |
| **PAS / PAS-O** | Problem (state the core symptom) → Agitation (amplify the cost of the status quo) → Solution (introduce it as the escape) → (Outcome: tie features to the promised result) |
| **BAB** (Before-After-Bridge) | Before (current problem + pain) → After (the ideal future) → Bridge (the product as the only path between them) |
| **Journey-Led / Promise-First** | Promise (`[Hero]` states the after-state on its own; pains deliberately left out) → Path (each step a section pairing `[Features]` + `[Benefits]`) → Action |
| **Transformation-Led** (use-case repeated) | Promise (hero states the outcome, lists every use case) → Frame (before vs after) → Instances (each use case its own section, proof in place) → Action |
| **Risk-Reversal** (trust-first) | Trust-anchor (`[Social proof]` above the fold) → Friction-removal (`[Comparison]` / `[Reference]` kill switching & fit objections) → De-risking (`[FAQ]` answers risk) → Safe-action (`[Pricing]` + guarantee/free trial microcopy) |
| **Feature-Led** (spec-driven) | Context (name the category/scope) → Core (`[Reference]` / capability matrix) → Proof under stress (`[Features]` through intense `[Use cases]` + `[Evidence]`) → Institutional check (compliance, authority) |
| **PASTOR** | Problem → Amplify → Story (a case/use-case) → Transformation (before → after) → Offer → Response (CTA) |
| **PPPP** (4Ps) | Picture (emotional transformation) → Promise (the product as the commitment) → Prove (`[Evidence]` + `[Social proof]`) → Push (`[CTA]` + offer) |
| **Story-Driven** | Inciting incident (before → after) → Conflict (personify the problem) → Revelation (the differentiator as a discovery) → Validation (use cases as case studies) |

**Reading a blend:** many real pages are a blend — a promise-first hero, a feature-led middle, a risk-reversal close. Name the weighting (which pattern dominates) and note where it hands off.
