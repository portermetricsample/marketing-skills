# Copy elements

The named slots a section is written into — the typographic parts, not the message. In a teardown, these are how you record *what each section is made of* inside the outline.

| Element | What it is |
|---|---|
| **Eyebrow** | Small label above the headline |
| **Headline** | The main statement of a section |
| **Subhead** | The line under the headline |
| **Body** | Running text |
| **Bullets** | A list |
| **Pull quote** | A sentence lifted out and set large |
| **Callout** | A boxed or highlighted block |
| **Stat** | A large figure with its label |
| **Badge** | A short tag attached to an item |
| **Button** | The clickable action |
| **Microcopy** | Small functional text: support lines, labels, tooltips, legal |

**Copy only** — visuals (image, demo, video) and layout (cards, grids, nav) are the designer's, not elements here.

**CTA strategy reads off these.** Count the buttons, note the primary verb, whether it repeats, and the microcopy that removes friction ("no credit card," "free forever"). One repeated primary action beats a scatter of competing CTAs.
