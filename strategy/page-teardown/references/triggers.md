# Persuasion triggers

Psychological mechanisms copy leans on to make the reader act. In a teardown, name the ones the page actually uses and where. They dress the argument — they don't replace it. (Robert Cialdini's principles of influence, plus a few from behavioral economics.)

| Trigger | How it works | What it looks like on a page |
|---|---|---|
| **Social proof** | Others like the reader already do it, so the choice feels safe | a user count, named customers, logos, testimonials |
| **Authority** | A credential or track record the reader can't easily verify | "10,000 teams," a named expert, a certification |
| **Reciprocity** | Give something genuinely useful first | free tools, templates, a resource library, an open teardown |
| **Scarcity** | A real limit on spots, time, or access | "we onboard 10 teams a quarter," a launch window |
| **Commitment** | A tiny first yes makes the bigger one easier | "start free, no credit card," "connect one account" |
| **Liking / Unity** | Sound like the reader; name an identity they already hold | "for marketers who'd rather ship than format," "whoever you are" |
| **Loss aversion** | Frame the cost of *not* acting | "every manual report is time you won't get back" |
| **Anchoring** | Plant a reference number before yours | "agencies charge $2k/mo — this: connect it and ask" |
| **Concreteness** | One named person with a detail beats a statistic | a single customer's face, handle, and result |
| **Curiosity** | Open a gap and hold the payoff | a headline that names the outcome but withholds the how |

**Proof ladder ≠ one trigger.** Strong pages stack social proof at *several grains* — an anonymous count, then named peers, then institutional numbers — each more credible than the last. Note the rungs and their order.
