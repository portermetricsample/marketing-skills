# examples/ — generated, not stored

Rendered report examples are **generated fresh** from the rules + tokens (see `../RULES.md`),
on the official `porter-design` themes (default `white`). They are **not committed here**, to
avoid baking real-account data into the repo.

Want to see what a finished report looks like? Use the reference layouts in **`../templates/`**
(e.g. `executive-report-white/`) — they paint only from the official tokens.

The earlier hand-built demos (on the retired `report-kit` style) were archived outside the repo
at `~/Downloads/porter-archive/old-examples/`.
