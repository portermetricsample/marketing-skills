# Document type: Presentation

A **slide-based deck** for a meeting or readout. One idea per slide, paced for someone
*presenting live* — not for solo reading.

## When to use
- "I'm presenting these results to the client / the board next week."
- The output is shown on a screen and narrated, not handed over to read alone.

## Shape
- Paginated slides, one headline + one visual per slide.
- Minimal text; highly visual. No subtitles/bylines/paragraphs crowding the idea.
- Usually a fixed-period readout (baked analysis), not live controls.

## Built from
- Components: `components/slides`, `components/charts`.
- Look: `porter-design` tokens (4 themes).
- Reference: the Acme Insurance exec deck pattern (`acme-gads-deck`).
