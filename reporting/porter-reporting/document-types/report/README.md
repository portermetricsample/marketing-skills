# Document type: Report

A **vertical narrative document** with supporting charts. Read top to bottom like a story:
headline → context → sections of insight, each backed by a chart or table.

This is Porter's default client deliverable.

## When to use
- "Send me a report on how the account did last month."
- The reader wants the *conclusion and the reasoning*, not to explore data themselves.

## Shape
- Single scrollable document (not paginated widgets).
- Each section = one insight + its evidence.
- Every metric compared (vs previous period / target / benchmark).

## Built from
- Look: `porter-design` tokens (4 themes, default `white`).
- Components: `components/layouts` (document scaffold) + `components/charts`.
- Narrative: a framework from `porter-analysis`.
