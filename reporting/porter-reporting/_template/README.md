# Template

Copy this folder to define a **new document type** or a **variant** of an existing one.
Keep every definition self-contained and following the same skeleton.

## Fill in

- **What it is** — one sentence.
- **When to use** — the user request that should produce this.
- **Shape** — structure, pagination, live vs snapshot.
- **Built from** — which `components/`, which design-system source, which framework.
- **Open questions** — anything undecided.

Mirror the structure of the existing document-type READMEs in `document-types/`.
